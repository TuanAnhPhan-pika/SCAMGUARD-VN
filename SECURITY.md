# Security

Không commit API key, credential, dữ liệu định danh hoặc signing key. Ollama key chỉ được đọc từ biến môi trường `OLLAMA_API_KEY` trên máy chạy server.

Nếu phát hiện bí mật hoặc dữ liệu nhạy cảm trong repository, hãy báo riêng cho maintainer thay vì mở issue công khai chứa chính dữ liệu đó.
